# Contributing

Thanks for helping with Coodsz Realm of Thrones.

- Found a mod that works or breaks with Coop? Use the [report form](https://github.com/Coodsz/Coodsz-RealmOfThrones/issues/new?template=mod-compat.yml).
- Found a bug in a tool? Open an issue and say what you did and what happened. Sending logs from the tools is not set up yet for Realm of Thrones, so use **Open client logs** on **Logs and help** (or **Open server logs** on **Logs** in the Server Tool) to find the log files.
- Want to change a file here? Make a branch, open a pull request, and say what changed and why. Never push straight to `main`.
- Do not edit `MODS.md` or the compatibility JSON by hand. A bot keeps them from player reports.
- The tool source code is private. For changes to how a tool works, open an issue.

Using an AI agent? Point it at [AGENTS.md](AGENTS.md) first.
